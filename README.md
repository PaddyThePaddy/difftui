## Keymaps

| Key               | Action                       |
| ----------------- | ---------------------------- |
| Arrow keys / hjkl | Navigation                   |
| q                 | Closet tab                   |
| c                 | Compare selected file/folder |
| o                 | Open selected filde / folder |
| g                 | Move to top                  |
| G                 | Move to bottom               |
| /                 | Filter files                 |
| ][                | Next/Previous difference     |
| =                 | Decouple side-by-side view   |
| Enter             | Expand/Collapse              |
| Ctrl + c          | Exit app                     |
| ? / F1            | Show help                    |
